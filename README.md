# QR Canvas

Create a clean, modern, SaaS-style QR Code Generator web application with a centered minimal professional design. The layout must use a fully responsive two-panel structure: left panel for input controls and right panel for a live QR preview. The controls panel should include a QR Type dropdown (Text, URL, WiFi, Contact) with dynamic fields that appear based on type, color pickers for QR foreground and background, QR size selector, logo upload option, and a clear primary Generate QR button. The preview panel must display a large QR code inside a soft card container with subtle shadow, a download button, placeholder when empty, and a clean error message area. Use modern SaaS UI styling similar to Stripe or Notion with soft rounded corners, balanced spacing, clean typography, smooth hover and focus states, light and dark mode support, and mobile responsiveness. The application should feel production-ready, minimal, and professional rather than a basic student interface, and visually match a polished QR generator SaaS landing tool.
